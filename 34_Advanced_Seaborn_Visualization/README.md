# Day 34 — Advanced Seaborn Visualization

## Overview
          Practiced advanced Seaborn visualizations using a sample business dataset containing product categories, regions, sales, profit, and customer counts.

## Concepts Covered
          - `hue` for comparing groups within categories
          - `palette` for chart color schemes
          - `errorbar=None` for removing error bars
          - `pivot()` for reshaping data into a matrix
          - `sns.heatmap()` for visualizing numerical values
          - `plt.subplots()` for combining charts in a dashboard

## Visualizations
          1. Grouped bar chart: sales by category and region
          2. Grouped bar chart: profit by category and region
          3. Profit heatmap: category versus region
          4. Sales heatmap: category versus region
          5. Combined dashboard: average sales, average profit, and regional profit

## Business Insights
          - Furniture has the highest sales and profit values in the sample.
          - South has the highest sales and profit for each category in this dataset.
          - Food has the lowest sales and profit values across the three regions.

## Important Note
          The dataset contains 12 illustrative observations. Results demonstrate visualization techniques and should not be treated as conclusions about a real business.

## Tools
          Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook
