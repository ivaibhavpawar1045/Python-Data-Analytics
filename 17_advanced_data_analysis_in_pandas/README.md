# Day 17 - Advanced Data Analysis with Pandas

## 📌 Overview

          - Day 17 focused on applying advanced Pandas techniques to a real-world supply chain dataset.

## 📌 Objective

          The main objective was to move beyond basic data manipulation and use Pandas for:

          - Conditional classification
          - Feature creation
          - Customer ranking
          - Product ranking
          - Profitability analysis
          - Boolean filtering
          - Business-oriented analysis
          - Comparing sales performance with profitability

          The session continued using the DataCo Supply Chain dataset from the previous mini project.

# 📊 Dataset

          The DataCo Supply Chain dataset was used for the analysis.

          The dataset contains approximately **180,519 records** and includes information related to:

          - Customers
          - Products
          - Sales
          - Profit
          - Discounts
          - Regions
          - Customer segments
          - Delivery risk
          - Orders
          - Shipping

          - The dataset was loaded in its original form.

          - The date column was left as `object` during the initial analysis because Day 17 focused mainly on conditional analysis and ranking rather than date-based analysis.

# 🛠️ Technologies Used

          - Python
          - Pandas
          - NumPy
          - Jupyter Notebook
