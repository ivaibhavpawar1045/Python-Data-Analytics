# 🐼 Day 10 – Merge, Join & Concat in Pandas

## 🎯 Objective

          - Learn how to combine multiple DataFrames using `merge()`, `join()`, and `concat()`. 
          - These operations are essential when working with data stored across multiple tables or files.

# 📚 Topics Covered

          - merge()
          - Inner Join
          - Left Join
          - Right Join
          - Outer Join
          - concat()
          - join()


# 💼 Business Concepts Learned

          - Combine employee and department datasets.
          - Understand different join types.
          - Merge data using a common key.
          - Combine DataFrames row-wise and column-wise.
          - Join DataFrames using indexes.

# 🧠 Key Takeaways

          - `merge()` combines DataFrames using common columns.
          - `concat()` combines DataFrames by rows or columns.
          - `join()` combines DataFrames based on indexes.
          - Inner Join returns only matching records.
          - Left Join keeps all rows from the left DataFrame.
          - Right Join keeps all rows from the right DataFrame.
          - Outer Join keeps all rows from both DataFrames.

# 📊 Methods Learned

          - merge() = Combine DataFrames using common columns |
          - concat() = Combine DataFrames row-wise or column-wise |
          - join() = Combine DataFrames using indexes |
