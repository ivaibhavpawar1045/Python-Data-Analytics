
## DAY 7 - DATA SORTING AND MANIPULATION

## OBJECTIVE - 

          - Learn how to organize, modify, and clean datasets using Pandas. 
            This session focuses on sorting data, renaming columns, removing unnecessary data, and handling duplicate record.

# 📚 TOPICS COVERED

          - sort_values()
          - sort_index()
          - rename()
          - drop()
          - drop_duplicates()

# 💼 Business Concepts Learned

          - Sort business data in ascending and descending order.
          - Organize datasets using index sorting.
          - Rename columns to improve readability.
          - Remove unnecessary rows and columns.
          - Identify and remove duplicate records.
          - Prepare clean datasets for business analysis.

# 🧠 Key Takeaways

          - `sort_values()` sorts data based on column values.
          - `sort_index()` sorts the DataFrame using row indexes.
          - `rename()` changes column or index names without modifying the data.
          - `drop()` removes rows or columns from a DataFrame.
          - `drop_duplicates()` removes duplicate records.
          - Most Pandas methods return a new DataFrame unless assigned back or used with `inplace=True`.
