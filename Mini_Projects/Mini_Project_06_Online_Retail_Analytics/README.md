# Mini Project 06 — Online Retail Analytics

## 📌 Project Overview

          This project analyzes the Online Retail II transaction dataset using Python and Pandas.

          The objective is to understand sales performance, customer behavior, product performance, geographical contribution, transaction trends, and cancellation activity.

## 🎯 Business Objective

          - Analyze overall retail performance
          - Identify high-performing countries
          - Identify high-value customers
          - Identify top-performing products
          - Analyze monthly revenue trends
          - Measure revenue contribution
          - Analyze cancellation transactions
          - Apply advanced Pandas techniques to business problems


## 📊 Dataset

          The dataset contains online retail transactions with the following fields:

          - Invoice
          - StockCode
          - Description
          - Quantity
          - InvoiceDate
          - Price
          - Customer ID
          - Country


## 🔄 Data Preparation

          The project included:

          - Loading multiple Excel sheets
          - Combining yearly datasets
          - Dataset exploration
          - Missing-value analysis
          - Duplicate detection and removal
          - Negative-price investigation
          - Cancellation identification
          - Missing description handling
          - Revenue calculation
          - Date feature engineering


## 💡 Key Business Insights

### 🌍 Country

United Kingdom was the dominant market, contributing approximately **84.91% of total revenue**.

### 👤 Customer

Customer **18102** generated the highest customer revenue of approximately **570,380.61**, contributing around **3.50%** of customer-attributed revenue.

### 🛍️ Product

**22423 — REGENCY CAKESTAND 3 TIER** was the highest-revenue product, generating approximately **314,045.02**.

### 📅 Time

**November 2011** recorded the highest monthly revenue at approximately **1.46 million**.

### 🔄 Cancellations

The United Kingdom recorded the highest number of cancellation transactions, with **16,291 cancellations**.

Cancellation transactions generated approximately **-1.46 million** in revenue.
