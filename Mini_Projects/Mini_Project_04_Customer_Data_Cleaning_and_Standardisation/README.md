# Mini Project 04 - Customer Data Cleaning & Standardization

## 📌 Project Overview

          - This project demonstrates how to clean and standardize customer data using Pandas string operations.
          - The dataset contains inconsistent text formatting, extra spaces, mixed letter cases, and old email domains. 
          - The objective is to transform the raw data into a clean and standardized dataset suitable for reporting and analysis.

## 🎯 Project Objectives

          - Remove unnecessary spaces from text columns.
          - Standardize customer names.
          - Standardize city names.
          - Convert email addresses to lowercase.
          - Replace old company email domains.
          - Extract first and last names.
          - Validate email domains.
          - Prepare a clean dataset for business reporting.

## 🛠️ Technologies Used

          - Python
          - Pandas
          - Jupyter Notebook

## 🚀 Future Improvements

          - Work with larger datasets (1000+ rows).
          - Validate email formats.
          - Detect duplicate customers.
          - Handle missing values.
          - Export cleaned data to Excel.
          - Build a Power BI dashboard using the cleaned dataset.
