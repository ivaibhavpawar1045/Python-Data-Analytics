## 📊 Mini Project 01 – Employee Data Analysis using Pandas

## 📌 Project Overview

           This project demonstrates the complete workflow of a Data Analyst using Python and Pandas. 
           The dataset contains employee information such as department, city, experience, salary, and performance ratings. 
           The project covers data exploration, cleaning, and business analysis to answer common HR-related questions.

# 🎯 Objectives

          - Load and explore employee data.
          - Perform data cleaning.
          - Identify duplicate records.
          - Analyze employee information.
          - Answer business questions using Pandas.
          - Practice real-world data analysis workflow.

# 🛠 Tools & Technologies

          - Python
          - Pandas
          - Jupyter Notebook
          - VS Code
          - Git & GitHub

# 📈 Business Analysis

          Solved the following business problems:

          - Employees with salary greater than ₹70,000
          - IT department employees
          - Employees with experience greater than or equal to 5 years
          - Top-paid employees
          - Renamed "Performance_Rating" to "Performance Score"
          - Selected required columns using `loc[]`
          - Displayed records using `iloc[]`

# 📚 Key Learnings

          - Understand the structure of a dataset before analysis.
          - Clean the dataset before generating reports.
          - Remove duplicate records based on business requirements.
          - Use Pandas efficiently for business analysis.
          - Write clean and readable analysis code.

# 🚀 Future Improvements

          - Add visualizations using Matplotlib and Seaborn.
          - Perform department-wise salary analysis.
          - Create interactive dashboards.
          - Export reports to Excel.
