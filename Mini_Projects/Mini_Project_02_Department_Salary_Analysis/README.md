# 📊 Mini Project 02 – Department Salary Analysis using Pandas

## 📌 Project Overview

          - This project demonstrates how to analyze employee salary data using Pandas GroupBy and Aggregation functions. 
          - The objective is to generate department-wise business reports and answer common HR analytics question

# 🎯 Objectives

          - Analyze department-wise salary.
          - Calculate average salary.
          - Count employees in each department.
          - Find highest and lowest salary.
          - Create professional summary reports using `agg()`.

# 🛠 Tools Used

          - Python
          - Pandas
          - Jupyter Notebook
          - VS Code
          - Git & GitHub

# 📊 Business Insights

          - IT department has the highest total salary.
          - IT department has the highest average salary.
          - Sales and IT have the highest employee count.
          - Vikram is the highest-paid employee.
          - Rahul is the lowest-paid employee.
