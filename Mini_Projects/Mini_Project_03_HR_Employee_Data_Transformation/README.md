# Mini Project 03 - HR Employee Data Transformation

## 📌 Project Overview

          - is project simulates a real-world HR data transformation task using Pandas.

## 🎯 Objectives

         -The objective is to clean and transform employee data to prepare it for reporting and business analysis.

## 📂 Dataset

          Columns:

          - Employee
          - Department
          - Salary
          - Experience

## 🛠️ Technologies Used

          - Python
          - Pandas
          - Jupyter Notebook

## 🎯 Learning Outcome

          After completing this project, I learned how to:

          - Transform data using map()
          - Replace values using replace()
          - Apply custom logic using apply()
          - Use lambda functions effectively
          - Solve real-world HR data transformation tasks

## 🚀 Future Improvements

          - Read dataset from CSV.
          - Export transformed data to Excel.
          - Create Power BI dashboard.
          - Perform department-wise salary analysis.
          - Visualize employee statistics.
