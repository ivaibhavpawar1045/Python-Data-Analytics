# Mini Project 7 — Online Retail II Analysis

## Objective

Analyze customer, product, country and cancellation performance using
advanced Pandas techniques.

## Dataset

Online Retail II

## Data Preparation

          - Removed duplicate transactions
          - Removed records with missing product descriptions
          - Preserved transactions with missing Customer IDs
          - Created Sales:

          - Sales = Quantity × Price

## Business Insights

          1. The United Kingdom is the dominant revenue market.
          2. Customer 18102 generated the highest customer-level sales.
          3. REGENCY CAKESTAND 3 TIER generated the highest product-level sales.
          4. Cancellation behavior varies substantially across countries.
          5. Monthly sales analysis using shift() enables period-over-period performance tracking.

## Skills Practiced

          Python, Pandas, Data Cleaning, EDA, Business Analysis,
