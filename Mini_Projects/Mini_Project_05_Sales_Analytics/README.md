# Mini Project 05 - Supply Chain Analytics

## 📌 Overview

          This project is a revision-based real-world data analytics project developed using Python and Pandas.

## 📌 Objective

          - The objective was to analyze a large supply-chain dataset, perform data-quality checks, transform the data, engineer useful features, perform business analysis, and generate actionable business insights.

## 📊 Dataset

          - The project uses the DataCo Supply Chain dataset.
          -  The original dataset contains a large number of supply-chain transactions and business-related attributes.

### Main areas covered

          - Customer information
          - Order information
          - Product information
          - Category information
          - Sales
          - Profit
          - Discounts
          - Regions
          - Customer segments
          - Delivery information
          - Shipping information
          - Order dates

## 🛠️ Technologies Used

          - Python
          - Pandas
          - Jupyter Notebook
