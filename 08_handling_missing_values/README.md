
## DAY 8 - HANDLING MISSING VALUES IN PANDAS

## OBJECTIVE - 

          -Learn how to identify, analyze, and handle missing values in a dataset using Pandas. 
          -Missing values are one of the most common challenges in real-world data analysis, and knowing how to deal with them is an essential skill for every Data Analyst.

# 📚 TOPICS COVERED

          - isnull()
          - notnull()
          - fillna()
          - dropna()

# 💼 BUSINESS CONCEPT LEARNED

          - Identify missing values before analysis.
          - Count missing values in each column.
          - Find available (non-null) values.
          - Replace missing values with meaningful defaults.
          - Remove incomplete records when necessary.
          - Decide between replacing or removing missing values based on business requirements.

# 🧠 KEY TAKEWAYS

          - `isnull()` identifies missing values.
          - `notnull()` identifies existing values.
          - `fillna()` replaces missing values without deleting records.
          - `dropna()` removes rows or columns containing missing values.
          - Missing values should always be handled before creating reports or dashboards.
          - Business context determines whether to use `fillna()` or `dropna()`.
