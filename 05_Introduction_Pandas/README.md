## 🧠 KEY TAKEWAYS

          - Series represents a single labeled column.
          - DataFrame represents tabular data with rows and columns.
          - `read_csv()` is used to load datasets.
          - `head()` and `tail()` preview data.
          - `info()` shows structure and data types.
          - `describe()` summarizes numeric columns.
          - Single brackets return a Series.
          - Double brackets return a DataFrame.
