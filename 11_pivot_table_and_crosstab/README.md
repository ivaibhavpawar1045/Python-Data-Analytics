# 🐼 DAY 11 - PIVOT TABLE AND CROSSTAB IN PANDAS

## 🎯 Objective

          - Learn how to create business reports and summary tables using `pivot_table()`, `pivot()`, and `crosstab()`.

# 📚 Topics Covered

          - pivot_table()
          - Multiple Aggregations
          - Multiple Index
          - pivot()
          - crosstab()

# 💼 Business Concepts Learned

          - Department-wise salary reports
          - Multiple aggregation reports
          - Department and city-wise analysis
          - Converting rows into columns
          - Category frequency analysis

# 🧠 Key Takeaways

          - `pivot_table()` creates report-style summaries with aggregation.
          - Multiple aggregation functions can be applied in a single pivot table.
          - Multiple indexes create hierarchical reports.
          - `pivot()` reshapes data without aggregation.
          - `crosstab()` counts the frequency between categorical variables.

# 📚 Key Learning Outcome

          - Today I learned how to generate business-ready summary reports using pivot tables, 
          - reshape data using `pivot()`, and analyze category frequencies using `crosstab()`. 
          - These techniques are widely used in business reporting and dashboard preparation.
