# Day 18 - Advanced GroupBy & Business Analysis

## 📌 Overview

          - Day 18 focused on advanced `groupby()` techniques and business-oriented analysis using the DataCo Supply Chain dataset.

## Objective

          - The main objective was to move beyond simple aggregation and learn how to:

          - Perform multiple aggregations
          - Create named aggregations
          - Analyze multiple business dimensions together
          - Find maximum values within groups
          - Rank records within groups
          - Compare total and average performance
          - Generate meaningful business insights

# 📊 Dataset

          - The DataCo Supply Chain dataset was used for today's analysis.

          - The dataset contains approximately **180,519 records** and includes information related to:

          - Customers
          - Products
          - Sales
          - Profit
          - Markets
          - Customer Segments
          - Orders
          - Regions
          - Shipping
          - Delivery
