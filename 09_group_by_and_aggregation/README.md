# 🐼 DAY 9 - GROUP BY AND AGGREGATION IN PANDAS

## 🎯 Objective

          - Learn how to summarize and analyze business data using Pandas `groupby()` and aggregation functions. 
          - These methods help transform raw data into meaningful business reports.

# 📚 Topics Covered

          - groupby()
          - sum()
          - mean()
          - count()
          - min()
          - max()
          - agg()

# 💼 Business Concepts Learned

          - Department-wise salary analysis
          - Employee count by department
          - Highest salary by department
          - Lowest salary by department
          - Average salary by department
          - Creating summary reports using aggregation

# 🧠 Key Takeaways

          - `groupby()` groups records based on common values.
          - `sum()` calculates total values.
          - `mean()` calculates average values.
          - `count()` counts records in each group.
          - `max()` finds the highest value.
          - `min()` finds the lowest value.
          - `agg()` performs multiple aggregation operations in a single command.
