
##  DAY 6 - DATA FILTERING AMD INDEXING IN PANDAS

## 🎯 OBJECTIVE

          - Learn how to filter, select, and index data efficiently using Pandas. This session focuses on applying business conditions, selecting rows and columns,
            and understanding the difference between label-based and position-based indexing.

# 📚 TOPICS COVERED

          - Data Filtering
          - Boolean Indexing
          - Comparison Operators
          - Multiple Conditions
          - AND (`&`)
          - OR (`|`)
          - isin()
          - between()
          - loc[]
          - iloc[]

# 💼 BUSINESS CONCEPT LEARNED

          - Filtering datasets based on business conditions.
          - Selecting records using multiple conditions.
          - Filtering multiple values from the same column.
          - Performing range-based filtering.
          - Selecting rows and columns using labels.
          - Selecting rows and columns using integer positions.
          - Writing clean, readable, and production-ready Pandas code.

# 🧠 KEY TAKEWAYS

          - Data filtering returns only rows that satisfy a condition.
          - Boolean Indexing works using `True` and `False` values.
          - `&` is used when **all conditions** must be true.
          - `|` is used when **at least one condition** must be true.
          - `isin()` is used for checking multiple values within the same column.
          - `between()` is used for range filtering and includes both boundary values by default.
          - `loc[]` is label-based indexing (row labels and column names).
          - `iloc[]` is integer position-based indexing (row and column positions).
          - Python slicing in `iloc[]` excludes the ending index.
